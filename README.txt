BULK UP - iPhoneで使う方法

このフォルダは、iPhone向けの増量管理Webアプリです。

【いちばん簡単な確認方法】
index.html をブラウザで開くと画面を確認できます。
ただし、iPhoneのホーム画面にアプリとして追加する機能（PWA）を使うには、
HTTPSで公開する必要があります。

【iPhoneのホーム画面に追加する方法】
1. このフォルダ一式をGitHubなどの静的サイト hosting にアップロードします。
   GitHub Pagesを使う場合は、リポジトリを作成してファイル一式を配置し、
   Settings → Pages → Deploy from a branch で公開します。
2. 発行された https://... のURLをiPhoneのSafariで開きます。
3. Safariの共有ボタン →「ホーム画面に追加」→「追加」を押します。
4. ホーム画面の Bulk Up アイコンから起動できます。

【記録について】
体重・チェック状況は、利用中のブラウザのローカルストレージに保存されます。
同じiPhone・同じブラウザで使ってください。SafariのWebサイトデータ削除などで
記録が消える可能性があります。記録画面の「CSVを書き出す」でバックアップできます。

【内容】
・目標体重 54kg → 70kg
・週3回を基本とした筋トレメニュー＋任意の4回目
・食事例、栄養目安、買い物候補
・日々の食事チェック
・体重記録、推移グラフ、CSV書き出し

カロリー2,300〜2,500kcalは開始時の仮目安です。実際の体重推移や活動量に合わせて調整してください。
体重増加は急がず、週平均を見ながら少しずつ進めてください。
